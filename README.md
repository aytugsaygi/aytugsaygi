### 🚧 Automatic Barrier Gate Control Software — `C`
*Optima Engineering Inc. · Jun 2025 — Jul 2025 · company-confidential project*

- Built the end-to-end control logic for an automatic barrier gate product from scratch in **C**, defining the open/close commands, sensor triggers and fault-state behaviour so the system operates reliably and predictably.
- Delivered the work in three stages: **core control functions** (sensor reading, trigger conditions, motor drive commands), **hardware deployment** (loading and verifying the software on the control board) and **iterative debugging** (condition tests, output checks).
- Resolved timing, sensor-response and state-transition faults by separating software-related issues from hardware-related ones and by splitting the control logic into small, testable functions — this sped up debugging and made the system behave consistently across scenarios.

### 💥 Collision Detection and Damage Diagnosis System — `LabVIEW`
*Çankaya University · Team project*

- Developed a sensor-based collision avoidance and damage diagnosis system together with my teammates.
- Used **infrared and sonar** sensors for distance tracking, and **piezoelectric and strain gauge** sensors to classify collision severity (normal, minor, critical); calibrated the system with our own measurements.
- Designed a **filter** to clean the raw data and built a LabVIEW interface with LED indicators for real-time monitoring.
- Takeaways: sensor integration, signal processing and system modelling.

### 🅿️ Vehicle Assignment Simulation for Parking Management — `MATLAB`
*Çankaya University*

- Developed a **rule-based** simulation in MATLAB that assigns vehicles entering the campus to the most suitable parking area.
- Modelled **five parking areas** with different capacities and rules (user type, vehicle size, electric/accessible parking).
- Vehicles were filtered against these constraints and assigned to the **lowest-cost** area based on driving distance, walking distance and penalty scores.
- Tested the algorithm under two traffic scenarios of 100 vehicles each, comparing access times, walking distances and rejection rates.
